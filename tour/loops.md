Go has only one looping construct.
That is For loop.

for i := 0; i < 10 i++ {
  do something here
}

init and post statements are optional

for ; true ; {
  do something here, its an infinite loop
}

or
just drop the semicolons

for true {
  same infinite loop
}

or maybe even better for infinite loops

for {
  same infinite loop
}
